# 登录、会话持久化与自动登录

通财航有两套完全独立的凭据：

| 凭据 | 用途 | 保存方式 |
|---|---|---|
| 统一身份认证（学号 / 工号 + 密码） | 校园卡、账单、财务、门户网费 | 学号默认记住；密码默认不保存 |
| 校园网（账号 + 密码） | zfw 流量、网费充值 | 账号默认记住；密码默认不保存 |

两套密码都只在用户**显式勾选「记住密码」**后才保存，默认关闭。

## 1. 会话持久化（默认行为）

登录成功后客户端保存的是**会话凭据**，不是密码：

| 凭据 | 存储 | 续期方式 |
|---|---|---|
| `CASTGC` | AndroidKeyStore AES/GCM 加密 | 重启后免密换票，换新的 `JSESSIONID` |
| `JSESSIONID` | AndroidKeyStore AES/GCM 加密 | 直接复用；失效后用 `CASTGC` 续期 |
| 校园网 Cookie（含 `PHPSESSID_8800`） | AndroidKeyStore AES/GCM 加密 | 直接复用；服务端续期时覆盖本地值 |

启动顺序（统一认证）：

1. 先用本地 `JSESSIONID` 试一次卡务读接口；
2. 失败且存有 `CASTGC` 时，走 CAS 免密续期，换新 `JSESSIONID`；
3. 都失效时才进入密码登录。开启「自动登录」后，第 3 步会用保存的密码自动提交一次。

校园网没有等价的长期票据，只有 Cookie。Cookie 失效后打开校园网登录页时，若已开启
「自动登录」，会用保存的密码自动走一次原生登录（RSA 公钥 + CSRF）。

## 2. 记住密码

- 开关在统一认证登录页与校园网登录页两处，状态共用；
- 密码只在**登录成功之后**写入，写入前不会把输入框内容落盘；
- 加密方式与 `CASTGC` 相同：AndroidKeyStore 中不可导出的 AES-256 密钥 + AES/GCM，
  SharedPreferences 中只保存 `gcm:<Base64(IV|密文)>`；
- 密钥库不可用时**不会**退回明文保存密码，而是放弃保存并写一条不含密码的告警日志；
- 关闭「记住密码」会立即删除已保存密码，并同时关闭「自动登录」；
- 退出登录（主界面「退出登录」）会清除两套密码、自动登录开关与全部会话；
  「设置 → 退出校园网」只清除校园网 Cookie，保留密码与自动登录开关，
  因此下次打开网费会按设置自动重新登录。

学号 / 工号与校园网账号始终记住（明文，不含密码）。旧版本「记住学号」开关已删除；
升级用户若之前没有勾选，首次打开登录页会从已保存会话里回填学号。

## 3. 自动登录

自动登录必须同时满足：

1. 已开启「记住密码」；
2. 已开启「自动登录」；
3. 本地确实有可解密的密码；
4. 学号 / 账号非空。

每次进入登录页最多自动提交一次，避免循环请求。

### 统一身份认证

| 结果 | 行为 |
|---|---|
| 会话恢复成功 | 直接进入首页，不提交密码 |
| 自动登录成功 | 校验业务会话后进入首页 |
| 账号或密码错误 | 清除保存的密码、关闭自动登录，提示手动登录 |
| 需要图形验证码 | 保留密码并展示验证码输入框，关闭自动登录；用户补齐验证码后继续 |
| 账号临时锁定 | 保留密码、关闭自动登录，避免继续累计失败次数 |
| 网络异常 | 保留设置，降级为手动登录（下次启动仍可自动尝试） |

### 校园网

| 结果 | 行为 |
|---|---|
| Cookie 仍有效 | 直接进入网费页，不提交密码 |
| 自动登录成功 | 保存新 Cookie，直接进入网费页 |
| 账号或密码错误 | 清除保存的密码、关闭自动登录，提示手动登录 |
| 需要图形验证码 | 保留密码并展示验证码输入框，关闭自动登录 |
| 需要短信验证码 | 保留密码并展示短信输入框，关闭自动登录 |
| 网络异常 / 页面改版 | 关闭自动登录，保留密码，可手动重试或改用学校官方网页登录 |

## 4. 存储键

`SharedPreferences` 文件名：`scp_session`（`android:allowBackup="false"`）。

| 键 | 内容 |
|---|---|
| `session_blob` | 统一认证会话（`studentId` / `openid` / `CASTGC` / `JSESSIONID`） |
| `zfw_session_blob` | 校园网会话（账号 / 姓名 / Cookie） |
| `remembered_student_id` | 学号 / 工号（明文） |
| `remembered_zfw_username` | 校园网账号（明文） |
| `cas_password_blob` | 统一认证密码（`gcm:` 密文） |
| `zfw_password_blob` | 校园网密码（`gcm:` 密文） |
| `cas_remember_password` / `cas_auto_login` | 统一认证「记住密码」/「自动登录」开关 |
| `zfw_remember_password` / `zfw_auto_login` | 校园网「记住密码」/「自动登录」开关 |

## 5. 相关文件

- `store/SecureStore.kt`：会话与密码的加密读写、开关联动
- `store/LoginPolicy.kt`：自动登录条件与失败分类
- `ui/LoginActivity.kt`：统一认证登录、会话恢复、自动登录
- `ui/ZfwLoginActivity.kt`：校园网原生登录、验证码 / 短信、自动登录
- `ui/SettingsFragment.kt`：退出校园网
- `ScpApp.kt`：会话恢复、续期与退出登录清理
